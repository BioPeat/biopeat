# BioPeat Diego

App personal de nutrición (enfoque Ray Peat / Georgi Dinkov) en un solo archivo, `index.html`, publicada con GitHub Pages e instalable en el móvil.

- **Qué es y cómo es Diego:** `CONTEXTO_BIOPEAT.md`
- **Dónde está cada cosa en el código:** `MAPA_DEL_CODIGO.md` (se genera con `python tools/mapa.py`)
- **Reglas para Jules y cualquier agente:** `AGENTS.md`
- **Prueba completa:** `python tests/smoke.py` (también se ejecuta sola en cada Pull Request)

Los datos de Diego viven solo en su móvil. Nunca se suben aquí.
