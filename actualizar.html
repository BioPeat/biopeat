Actualizar BioPeat

Esta página aplica los cambios de tu IA (Gemini o Claude) y los comprueba antes de que lleguen a tu app. Tus datos nunca se modifican aquí.

📘 Guía paso a paso (léela la primera vez)

Qué es esta página

Es tu «control de calidad». Tu IA escribe los cambios, esta página los aplica a una copia de la app, la arranca, pulsa por todas las secciones con tus datos reales (en una copia aislada) y solo te deja descargar la versión nueva si todo funciona. Tu app y tus datos no se tocan nunca desde aquí.

Preparación (solo la primera vez)

  1. Sube a GitHub index.html y actualizar.html (Add file → Upload files → Commit changes).
  2. En Gemini: Gems → Nuevo Gem → «BioPeat Dev» → pega GEM_BIOPEAT_DEV.txt. En Claude: Proyectos → «BioPeat Dev» → pega CLAUDE_INSTRUCCIONES.txt y sube CONTEXTO_BIOPEAT.md.
  3. Guarda esta página en marcadores. Es la dirección de tu app con /actualizar.html al final (ejemplo: tu-usuario.github.io/biopeat/actualizar.html).

Cada cambio (unos 5 minutos)

  1. Paso 1: Gemini → «Descargar archivo completo». Claude → «Descargar archivo ligero» (sin estilos, gasta menos límite).
  2. Abre «BioPeat Dev» (Gem o proyecto de Claude), empieza un chat nuevo, adjunta ese archivo y escribe lo que quieres, como si se lo dijeras a una persona. Puedes pedir varias cosas a la vez.
  3. Cuando responda, pulsa «Copiar» en su respuesta (copia TODA) y pégala en el Paso 2. Pulsa «Aplicar y comprobar».
  4. Si sale ✗ rojo: «Copiar mensaje del error» (incluye el bloque, la línea y el trozo de código que falla) → pégalo en el mismo chat → copia su nueva respuesta → bórrala del Paso 2, pega la nueva y vuelve a comprobar. Si solo trae los bloques corregidos, la página los combina con los anteriores.
  5. Si sale ✓ verde: para cambios pequeños puedes subirlo directamente. Para cambios grandes: «Copiar texto para la REVISIÓN» → pégalo en el mismo chat. Si la IA contesta «❌ HAY QUE CORREGIR», trata su respuesta como una nueva (vuelve al punto 3).
  6. Con ✅ APROBADO: pulsa «Descargar index.html nuevo» y «Guardar también la versión anterior».
  7. En GitHub: Add file → Upload files → arrastra el index.html nuevo → Commit changes. Espera 1-2 minutos.
  8. Abre la app, recarga, mira que en Más → Ajustes → Estado de la app sale la versión nueva y haz la prueba que te dijo la IA.

Si algo no te gusta después de subirlo

Sube el archivo «index_anterior_vNN.html» renombrado a index.html y vuelves a la versión de antes en 2 minutos. Tus datos no se pierden: viven en el móvil, no en el archivo.

Consejos

  • Hazlo desde el ordenador: copiar, pegar y subir archivos es mucho más cómodo.
  • Un chat nuevo para cada cambio, siempre con el archivo del Paso 1 (así nunca trabaja sobre una versión vieja).
  • Si falla algo en la app: cuéntaselo a la IA como una petición (qué pulsaste, qué esperabas, qué pasó, captura).
💻 Subir versiones con GitHub Desktop (recomendado)

Evita subidas a medias: copias los archivos en una carpeta y pulsas dos botones.

Instalar (solo la primera vez)

  1. Descarga e instala GitHub Desktop desde desktop.github.com.
  2. Ábrelo y pulsa Sign in to GitHub.com con tu cuenta.
  3. Pulsa File → Clone repository, elige BioPeat/biopeat y pulsa Clone. Se crea la carpeta Documentos\GitHub\biopeat en tu ordenador.

Cada vez que haya una versión nueva

  1. Descomprime el ZIP (o coge el index.html que descargues aquí).
  2. Copia los archivos dentro de Documentos\GitHub\biopeat y elige Reemplazar.
  3. En GitHub Desktop verás la lista de cambios. Abajo a la izquierda escribe un resumen (por ejemplo «v43») y pulsa Commit to main.
  4. Arriba pulsa Push origin. Listo: en 1-2 minutos está publicada.

Si Push origin no aparece, pulsa antes Fetch origin.

🤖 Qué subir al Gem de Gemini y al proyecto de Claude tras cada versión
  • Siempre: CONTEXTO_BIOPEAT.md y MAPA_DEL_CODIGO.md (borra los viejos y sube los nuevos).
  • Solo si cambia: AGENTS.md (lo dirá el mensaje de la versión).
  • Nunca: index.html. Se lo das en cada chat con el Paso 1 de esta página, así siempre trabaja sobre la versión real.
  • Las instrucciones del Gem y del proyecto no se tocan.

Comprobación: chat nuevo → «¿Qué versión es la actual?». Debe contestar la versión que ves en la app.
